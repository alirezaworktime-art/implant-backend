# طرح درمان ایمپلنت — نسخه‌ی پشتیبان کامل

این پوشه همه‌چیزِ لازم برای راه‌اندازی دوباره‌ی سایت روی یک حساب دیگر را دارد.

## محتوا
- `data.json` — همه‌ی اطلاعات: پرونده‌ها و طرح‌های درمان، جلسه‌های جراحی، تنظیمات و تعرفه‌ها، رمزهای دستیار جراحی و انباردار (به‌صورت رمزنگاری‌شده)، انبار و گردش انبار
- `site/index.html` — نسخه‌ی کامل سایت (همانی که الان روی سرور است)
- `site/index-source.html` — همان سایت با آدرس سرور خالی (برای ساختن نسخه‌ی تازه)
- `worker_core.js` — کد آماده‌ی سرور Cloudflare (سایت + API) برای کپی مستقیم
- `src/` — کد منبع سرور و اسکریپت‌های ساخت
- `apps-script/Code.gs` — کد Google Apps Script (پشتیبان PDF در Drive و ایمیل)
- `android/android.yml` — ساخت اپ اندروید با GitHub Actions
- `docs/decisions.md` — همه‌ی تصمیم‌ها و قوانین طرح درمان
- `restore.html` — صفحه‌ی بازیابی اطلاعات در سرور تازه

## راه‌اندازی روی حساب تازه‌ی Cloudflare (حدود ۱۵ دقیقه)
1. در dash.cloudflare.com ثبت‌نام کنید (رایگان).
2. **Storage & Databases → D1 → Create**: نام `implant-db`.
3. **Workers & Pages → Create → Worker**: یک نام بدهید (مثلاً `implant-api`) و Deploy کنید.
4. در همان Worker: **Settings → Bindings → Add → D1 database**: نام متغیر `DB` و پایگاه `implant-db`.
5. **Edit code**: کل محتوای فایل `worker_core.js` را جایگزین کد کنید. در خط `const IMPORT_KEY='';` بین دو علامت یک کلید دلخواه بنویسید (مثلاً `const IMPORT_KEY='';`) و **Deploy** کنید.
6. فایل `restore.html` را در مرورگر باز کنید، آدرس Worker تازه، همان کلید و فایل `data.json` را بدهید و «شروع بازیابی» را بزنید.
7. دوباره کد Worker را باز کنید، کلید را خالی کنید (`const IMPORT_KEY='';`) و Deploy کنید.
8. آدرس Worker تازه را باز کنید: سایت با همه‌ی اطلاعات بالا می‌آید. رمزهای ورود همان رمزهای قبلی است.

نکته: در `worker_core.js` آدرس سرور قبلی فقط برای نسخه‌ی فایل محلی است؛ سایتی که از خود Worker باز شود، خودکار به همان Worker وصل می‌شود.
